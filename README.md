# JevSamples — Jev Rogue

A spectator PWA where TypeSafe Jev autonomously plays **Rogue 5.4.4**.

The game engine is [`@ticktockbent/rogue-ts`](https://github.com/TickTockBent/rogue-ts). Rogue remains authoritative: Jev only chooses bounded keyboard inputs, while `rogue-ts` validates movement, combat, inventory, hunger, dungeon generation, and every state transition.

## Interaction model

```text
rogue-ts 80×24 CursesBackend
        ↓
current terminal + recent messages + known inventory
        ↓
Cloudflare Worker
        ↓
TypeSafe Jev Choice
        ↓
one bounded Rogue key
        ↓
rogue-ts
```

There is no human player input. The UI only controls observation/execution:

- **RUN** — Jev plays with an additional 0.8 s observer delay between top-level commands.
- **FAST** — no artificial delay; the TypeSafe response time is the pacing limit.
- **STEP** — execute one Rogue command, including any follow-up item/direction prompt needed by that command.
- **PAUSE** — stop before the next top-level command.
- **FOLLOW @** — recenter the scrollable viewport on the player. Touch/dragging the terminal releases follow.
- **NEW RUN** — reload with a fresh RNG seed.

The underlying Rogue terminal remains 80×24. On phones it is shown inside a square, touch-scrollable viewport instead of shrinking the game rules to a different terminal size.

## Jev boundary

The Worker sends one `Choice` question per required Rogue input. Normal turns expose a bounded command set (8-way movement, search, rest, stairs, pickup, inventory, and item-use commands). Follow-up prompts use smaller sets such as directions, hands, or known pack slots.

The TypeSafe API key stays in the Worker secret and is never shipped to browser JavaScript.

## Local / Cloudflare setup

```sh
npm install
npx wrangler secret put TYPESAFE_API_KEY
npm run dev
```

Build:

```sh
npm run build
```

Deploy:

```sh
npm run deploy
```

`web/` is the public surface. `web/app.js` is generated by esbuild and is intentionally not committed. `scripts/stamp.mjs` stamps the current commit hash into static asset URLs and the Service Worker cache identity.

## Dependencies

- `@ticktockbent/rogue-ts@0.1.2` — MIT, faithful TypeScript port of Rogue 5.4.4.
- `esbuild` — bundles the browser entry point for the static PWA.
